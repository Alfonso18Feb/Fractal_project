# Fractal_project
## Aqui tienes programados varios ejemplos de los fractales para que los puedas ver visualmente.
### Para verlos tienes que tener instalado visual studio code con python. Tambien debe instalarse las librerias de matplotlib.pyplot (commando: pip install matplotlib) y también instalar numpy si no lo tienes (comando:pip install numpy)
### Con todos las libreria descargadas puedes correr el programa y pedir que fractal quieres que te dibujen. Por favor no supero los numeros puestos antes del maximo ya que o si no se carga el programa.
## Para terminar también puedes hacer zum al fractal para comprobar que si cambias de dimension no afecta al fractal
